# Training environment on AMD ROCm for Windows (TODO.md A43; CHANGELOG.md 2026-09-14).
#
# Target: Windows 11, AMD Radeon RX 9060 XT, Python 3.12 (required both by the
# ROCm wheels and by the prebuilt C++ extension, memory/gotchas.md), AMD
# Adrenalin driver 26.2.2 (required by AMD for the 7.2.1 PyTorch release).
# Source: AMD's "Install PyTorch on Windows" and Windows support matrix pages,
# ROCm 7.2.1 / PyTorch 2.9.1.
#
# This is the project's one environment. torch-directml is deliberately absent:
# it pins torch 2.4.1 and cannot share a venv with this torch. Run from the repository root.
#
# Create it with Python 3.12 explicitly. On this machine a bare `python`
# resolves to 3.14 (C:\Python314), and every wheel below is cp312-only, which
# pip reports as "is not a supported wheel on this platform":
#
#   py -3.12 -m venv .venv
#   .venv\Scripts\python.exe -m pip install --no-cache-dir -r requirements.txt
#   .venv\Scripts\python.exe -c "import torch; print(torch.__version__, torch.cuda.is_available(), torch.cuda.get_device_name(0))"
#
# ROCm builds of PyTorch expose the GPU through the torch.cuda API, so
# utils/train.py's detect_device() picks it up as "CUDA / ROCm" unchanged.
